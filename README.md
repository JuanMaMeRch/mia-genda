# Mia Genda

Mi agenda personal: calendario, tableros y avisos, en una sola página web.

Se abre aquí: https://juanmamerch.github.io/mia-genda/

En este repositorio está **solo la aplicación** (los archivos que se ven en el navegador).
Los datos de la agenda no están aquí: se guardan aparte y solo se ven con la contraseña de su dueño.

## Qué hay

| Archivo | Para qué sirve |
| --- | --- |
| `index.html` | La aplicación entera, en un solo archivo. Arriba del todo lleva el bloque `CONFIG`. |
| `sw.js` | Hace que funcione sin conexión y que lleguen los avisos. |
| `manifest.webmanifest` | Permite instalarla en el móvil o en el ordenador como una app. |
| `icons/` | Los iconos. |

## Cómo se actualiza

Se sustituyen estos archivos por los nuevos (los de la carpeta `publicar`) y, en uno o dos minutos, la dirección de arriba enseña la versión nueva.
